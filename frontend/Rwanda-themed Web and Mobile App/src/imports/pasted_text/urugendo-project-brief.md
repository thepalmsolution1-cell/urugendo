====================================================
1. PROJECT OVERVIEW
====================================================

URUGENDO is a Rwanda-based Experience Planning and Booking Platform.

It is not just a tourism website.

It is not just a hotel booking website.

It is not simply an event listing platform.

URUGENDO helps people discover, plan, organize, budget, and book experiences.

The platform should serve both:

1. Rwandans
2. International visitors

Users should be able to plan different experiences, including:

- Trips

====================================================
2. THE PROBLEM URUGENDO SOLVES
====================================================

Planning an experience is often fragmented.

For example, someone planning a weekend trip may need to separately search for:

- Transport
- Hotel
- Restaurants
- Activities
- Attractions

Someone planning a birthday may separately search for:

- Venue
- Restaurant
- Cake
- Decoration
- Photographer
- Entertainment
- Transport

Someone attending a concert may need to organize:

- Ticket
- Dinner
- Transport
- Accommodation

The user often has to use multiple platforms, social media pages, websites and phone calls.

They also have to calculate the total cost themselves.

URUGENDO solves this problem by providing one platform where users can:

- Discover services
- Build an experience
- Set a budget
- See estimated costs
- Customize services
- Save an experience
- Save toward a future trip or adventure
- Request reservations
- Book participating services
